# 🔄 palindrome

Palindrom kontrolü, en uzun palindrom alt dizisi bulma ve metin istatistikleri.

## Kurulum
```bash
cargo build --release
```
## Kullanım
```bash
palindrome check "kayak"
palindrome longest "racecarabacaba"
palindrome stats "A man a plan a canal Panama"
```
